NAME
    ason2b - Convert ASON to and from ASONB

USAGE
    ason2b [options] [INPUT]

ARGUMENTS
    INPUT                   Input file (defaults to standard input)

OPTIONS
    -r, --reverse           Convert ASONB input to ASON
    -o, --output OUTPUT     Write output to this file (defaults to standard output)
        --complete SHELL    Print a completion script to standard output
                            Supported shells: bash, zsh, fish, PowerShell
    -h, --help              Show help information
    -V, --version           Show version information

EXIT STATUS
    0   Successful conversion, help, version, or completion output
    1   Invalid arguments, such as an unknown option or an unsupported completion shell
    2   Invalid input, a format conflict, or ASONB output directed to a terminal
    3   Failed conversion: the input is valid but cannot be represented in the output format
    4   I/O error while reading the input or writing the output

DESCRIPTION
    By default, the command converts ASON input to ASONB output. With `-r`, it converts ASONB
    input to ASON output.

    Input extensions `.ason` and `.asonb` select ASON and ASONB, respectively. Extensions
    are case-sensitive. A recognized input extension takes precedence over the input header.
    Without one, the ASONB header selects binary input; otherwise, the input is treated as
    ASON. An input that does not match the direction, such as ASONB input without `-r`,
    is a format conflict.

    The output file name must match the direction: `.asonb` by default and `.ason` with `-r`.
    Any other name or a name with no extension is a format conflict. This check does not apply
    to standard output.

    Exit status 1 means the command line itself is invalid, regardless of the input or file
    names, such as an unknown option. Exit status 2 means the options are valid on their own but
    contradict the actual input or output, such as ASONB input without `-r`, `-r` with ASON input,
    or an `.ason` output file without `-r`, or the input document itself is invalid. Format
    conflicts are detected before the output is opened, so no output file is created or overwritten.

    If no input file is specified, input is read from standard input.

    If no output file is specified, output is written to standard output.

    ASONB output cannot be written directly to a terminal. An output file is created or truncated
    before conversion and may be empty or partial on failure; use a different file from the input.

EXAMPLES
    * Convert an ASON file to ASONB
      ason2b input.ason -o output.asonb

    * Convert an ASONB file to ASON
      ason2b -r input.asonb -o output.ason

    * Convert ASON from standard input to an ASONB file
      echo '{key: "value"}' | ason2b -o output.asonb

    * Convert ASON from standard input to ASONB, then back to ASON
      echo '{key: "value"}' | ason2b | ason2b -r
